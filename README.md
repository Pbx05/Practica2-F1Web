## Uso de IA

He utilizado la IA en este trabajo sobre todo para:
* Mejorar el diseño con CSS.
* Para poder evitar errores en la extraccion de los datos de la API
* Como organizar bien la tabla de las clasificaciones para los datos.

### Prompts principales

* **Organizacion de la tabla**
  > *Quiero mostrar la tabla de las clasificaciones pero no se muy bien como organizarla para mostrar adecuadamente los datos que he sacado de la API, como podria hacerlo?*
  
  Este prompt me ayudo a poder entender y mostrar la parte casi mas importante de mi web

### Validación del código

He tratado de evitar que me diera el código resuelto para comprender bien cada paso. En las partes donde sí me proporcionó código como puede ser con la organización de la tabla de clasificaciones o la gestión de errores en la extracción de datos de la API, no fue nada que no supiera replicar una vez entendida la lógica. 

Para verificar lo generado, siempre leía la explicación, comprendía el motivo de la solución y continuaba con ella solo si me parecía correcta; si no, la corregía a mano por código propio de mejor calidad.
